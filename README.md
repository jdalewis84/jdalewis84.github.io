# Road Code Quest 🇳🇿

A gamified app for learning the New Zealand Road Code. It has 25 stops from Cape Reinga to Bluff, 500+ questions, 228 searchable rules and a mock theory test, and it works offline.

**Install on iPhone:** open **https://jdalewis84.github.io** in Safari → tap **Share** → **Add to Home Screen**. Open it once while online, and after that it works with no signal.

Unofficial study aid based on the NZTA Road Code (including rule changes from 1 October 2026). Licensing rules change on 25 January 2027, so always check https://www.nzta.govt.nz/roadcode before your test.
